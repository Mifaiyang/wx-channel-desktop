# 视频号下载助手 · 流光版

由 [Mifaiyang · 皓舟](https://github.com/Mifaiyang) 制作的 Windows 图形助手，下载内核来自 [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel)。

## 下载与使用

在 [Releases](https://github.com/Mifaiyang/wx-channel-desktop/releases) 下载 Windows ZIP，完整解压后运行「视频号下载助手.exe」。点击「启动服务」，看到「已就绪」后进入电脑微信的视频号。

首版为公开预览。程序未签名，Windows 智能应用控制可能拦截。首次启动时，上游内核可能提示安装 HTTPS 代理根证书并调整代理设置。

感谢 nobiyou 和所有贡献者。随包内核为 v5.7.16，附有上游 MIT 许可证。
